# Report-engine template models: fact sheet

Scope: facts only, with source URLs. "UNVERIFIED" marks items that could not be confirmed from a source. Collected 2026-10-13 by web search (subagent report, kept in its original language as evidence).

## 1. JasperReports (JRXML)
- Format: XML `.jrxml` compiled to `.jasper`; visual designer Jaspersoft Studio. Sections (each holds one fixed-height `<band>`, all optional): title, pageHeader, columnHeader, groupHeader, detail, groupFooter, columnFooter, pageFooter, lastPageFooter, summary, background (drawn behind every page, cannot overflow), noData (https://jasperreports.sourceforge.net/api/net/sf/jasperreports/engine/JRSection.html)
- Layout: absolute x/y inside bands. Element `positionType` Float/FixRelativeToTop/FixRelativeToBottom; `stretchType` NoStretch/RelativeToTallestObject/RelativeToBandHeight; `isStretchWithOverflow`; `isRemoveLineWhenBlank`; `isPrintWhenDetailOverflows`; `isPrintRepeatedValues`; `isPrintInFirstWholeBand`; band `splitType` Stretch/Prevent/Immediate; group `footerPosition` Normal/StackAtBottom/ForceAtBottom/CollateAtBottom, `isStartNewPage/Column`, `isResetPageNumber`, `isReprintHeaderOnEachPage`, `minHeightToStartNewPage`, `keepTogether`; report `columnCount`+`printOrder` Vertical|Horizontal (newspaper), `isFloatColumnFooter`, `isSummaryNewPage`, `whenNoDataType` NoPages/BlankPage/AllSectionsNoDetail/NoDataSection; `<subreport>` with parameters/returnValues; `<crosstab>` (https://infosys.ars.usda.gov/svn/code/third_party/Jasper_Reports/jasperreports-4.6.0-project/jasperreports-4.6.0/dist/docs/schema.reference.html)
- Data: fields, parameters, variables (`resetType` None/Report/Page/Column/Group; calculation Count/Sum/Average/Lowest/Highest/…), expressions in Java/Groovy (`language`), `evaluationTime` Now/Report/Page/Column/Group/Band/Auto (Report = page N of M); `resourceBundle` i18n; `<style>` with conditionalStyle; `<template>` = `.jrtx` style templates (same URL)
- Output: exporters PDF, XLSX, DOCX, PPTX, ODT, HTML, CSV, plain text, Graphics2D, Java Print Service (https://jasperreports.sourceforge.net/api/net/sf/jasperreports/export/class-use/Exporter.html)
- Filler/blank rows, raw printer languages: none found. UNVERIFIED.

## 2. Crystal Reports (.rpt)
- Format: proprietary binary OLE2 container, signature "Crystal Reports" (PRONOM fmt/1648); designer-only (https://www.nationalarchives.gov.uk/PRONOM/fmt/1648)
- Areas: Report Header, Page Header, Group Header(s), Details, Group Footer(s), Report Footer, Page Footer; group areas appear when grouping is added (https://www.vision33.com/hubfs/Carls-Crystal-Reports/Lesson3/Lesson%203%20Reports%20Designer.pdf)
- Section Expert: New Page Before/After, Reset Page Number After, Suppress Blank Section, Underlay Following Sections (watermarks), Print at Bottom of Page, Format with Multiple Columns (Details only; Across-then-Down / Down-then-Across), Keep Together; object Can Grow / Keep Object Together; newer Clamp Page Footer / Reserve Minimum Page Footer (https://www.vision33.com/hubfs/Carls-Crystal-Reports/Lesson6/Notes%20if%20any.pdf ; https://userapps.support.sap.com/sap/support/knowledge/en/2451922 ; https://kenhamady.com/cru/?p=2994)
- Special fields Page N of M, Total Page Count; using them forces full render before display/export (https://www.teachucomp.com/insert-special-fields-in-crystal-reports-tutorial/ ; https://answers.sap.com/questions/6178436/page-n-of-m-function-page--greater-than-number-of-.html)
- Wizards: Standard, Cross-Tab, Mailing Label, OLAP; a label-wizard report cannot be converted to a regular one (https://learning.sap.com/learning-journeys/discovering-sap-crystal-reports/creating-a-report-using-the-report-wizard_db1765af-a42d-4abc-bdd4-27f5342e1492 ; https://kenhamady.com/cru/?p=3021)
- Export: PDF, XLS/XLSX (2020+), Word (RTF), RTF, CSV, TTX, Text, XML, HTML 3.2/4.0, Record Style; Excel "page-based" vs "data only" (https://userapps.support.sap.com/sap/support/knowledge/en/1200157)
- Formula language and raw printer languages: not checked. UNVERIFIED.

## 3. Eclipse BIRT (.rptdesign)
- XML `.rptdesign`; `.rptlibrary` shared components; `.rpttemplate`; Eclipse designer with Layout and XML Source tabs (https://www.eclipse.org/community/eclipse_newsletter/2015/september/article3.php)
- Not banded: flowing page of items Label, Text, Dynamic Text, Data, Image, Grid, List, Table, Chart, Cross Tab; Table/List have header/detail/footer slots and groups; Grid nestable for layout (same URL)
- Master page: Simple Master Page with header/footer slots and `headerHeight`/`footerHeight`; orientation Portrait/Landscape/Auto (ignored for Custom page type); multiple master pages assignable per section via page breaks (https://wiki.eclipse.org/ISimpleMasterPageModel_(BIRT) ; https://forums.opentext.com/forums/discussion/61095/birt-multiple-master-pages)
- Table "Repeat Header" under Page Break; no repeating table footer, workaround = page variables in master-page footer; results vary by emitter (https://forums.opentext.com/forums/developer/discussion/50464/displaying-table-header-and-table-footer-in-all-the-pages)
- Data sources (JDBC, XML, flat file, scripted), data sets, parameters; JavaScript expressions; event handlers in JavaScript or Java: initialize/prepare/beforeFactory/afterFactory/beforeRender/afterRender, item onPrepare/onCreate/onRender/onPageBreak (https://www.eclipse.org/lists/birt-dev/msg00457.html)
- Localization: `.properties` resource files, text keys on labels (newsletter URL above)
- Emitters: HTML, Paginated HTML, PDF, XLS, DOC, PPT, ODS, ODP, ODT, PostScript (https://eclipse-birt.github.io/birt-website/docs/overview-extensibility/)

## 4. Microsoft SSRS (RDL)
- RDL = XML `.rdl`; designers Report Builder, Report Designer (SSDT), Power BI Report Builder (https://learn.microsoft.com/en-us/sql/reporting-services/report-builder/export-reports-report-builder-and-ssrs)
- Page model: page header, body, page footer; no report header/footer areas (items at top/bottom of body); header/footer may hold text, images, lines, rectangles, expressions; direct field refs only with exactly one dataset; per-page totals via `Sum(ReportItems!X.Value)`; PageNumber/TotalPages only in header/footer; totals differ per renderer (https://learn.microsoft.com/en-us/sql/reporting-services/report-design/page-headers-and-footers-report-builder-and-ssrs)
- Tablix = generic grid; templates table (row groups), matrix (row+column groups), list (free-form layout for forms/invoices, multiple peer data regions, repeats per row/group); nested data regions; rectangle, subreport; `NoRowsMessage`; sort/filter/group set on the data region (https://learn.microsoft.com/en-us/sql/reporting-services/report-design/tables-matrices-and-lists-report-builder-and-ssrs ; https://learn.microsoft.com/en-us/power-bi/paginated-reports/report-design/create-invoices-forms-lists-report-builder)
- Tablix members: KeepWithGroup, KeepTogether, RepeatOnNewPage (not for column groups); "Repeat header rows on each page" (https://technet.microsoft.com/en-us/library/dd220573)
- Renderers: data (CSV, XML, Atom), soft page-break (Excel, Word, MHTML/HTML), hard page-break (PDF, TIFF/Image incl. BMP/EMF/GIF/JPEG/PNG, PowerPoint); page breaks carry page names and ResetPageNumber; `RenderFormat` global for per-renderer layout (export page above)
- Multi-column (Columns) honoured only by PDF/TIFF; others render one column (https://msdn.microsoft.com/fi-fi/library/ms155816(v=sql.90))
- Globals PageNumber, TotalPages, OverallPageNumber, OverallTotalPages (https://technet.microsoft.com/en-us/library/dd255216)

## 5. MESCIUS/GrapeCity ActiveReports
- Three report types: Section (banded, `.rpx` XML, event-driven code), Page (fixed page layout "FPL", `.rdlx`), RDL (continuous page layout "CPL", `.rdlx`, SSRS-RDL based) (https://developer.mescius.com/blogs/page-vs-rdl-vs-section-reports-in-net-c-sharp-application ; https://developer.mescius.com/activereportsnet/docs/latest/online/exporting-page-rdl-section-reports.html)
- Roots: Data Dynamics (Columbus, OH) acquired Oct 2008 by GrapeCity (Sendai; founded 1980 as Bunka Orient), which had sold/localized it in Japan for >10 years; Japanese "J" editions (e.g. 16.0J, `GrapeCity.ActiveReports.ja`); GrapeCity renamed MESCIUS Nov 2023 (https://en.wikipedia.org/wiki/GrapeCity ; https://www.mrweb.com/drno/news9060.htm ; https://docs.mescius.jp/help/activereports-14/available-packages.html)
- Section report: ReportHeader/Footer, PageHeader/Footer, GroupHeader/Footer (always paired), Detail; section props CanGrow, CanShrink, KeepTogether, NewPage (before/after), NewColumn, RepeatStyle (group header per page/column), UnderlayNext; Detail ColumnCount/ColumnDirection/ColumnSpacing (https://help.grapecity.com/activereports/webhelp/AR13/GrapeCity.ActiveReports~GrapeCity.ActiveReports.SectionReportModel.Detail_properties.html ; https://helpcentral.componentone.com/nethelp/AR8help/AR8_HelpOnlineEN/SectionReportStructure.html)
- Page report (FPL): controls stay fixed at run time; table has FixedHeight; overflow routed by `OverflowName` to an OverflowPlaceHolder on the same page or a differently designed page tab, chained; `RepeatBlankRows` None/FillPage/FillGroup (ex-`RepeatToFill`) pads blank rows to FixedHeight (https://developer.mescius.com/activereportsnet/docs/latest/online/repeat-blank-rows.html ; https://helpcentral.componentone.com/nethelp/ar7help/onlineen/OverflowDataInMultiplePages.html ; https://helpcentral.componentone.com/nethelp/AR8help/AR8_HelpOnlineEN/FPL.html)
- TextBox `SummaryType` (GrandTotal/PageTotal/PageCount…) + `SummaryRunning` None/Group/All for running totals (https://help.grapecity.com/activereports/webhelp/AR9/GrapeCity.ActiveReports.v9~GrapeCity.ActiveReports.SectionReportModel.SummaryRunning.html). A named 繰越 (carry-forward) feature: not found. UNVERIFIED.
- `.rpx` via `SaveLayout(XmlWriter)`, UTF-8; code-behind not saved (use scripting) (https://help.grapecity.com/activereports/webhelp/AR12/SaveandLoadReportLayoutFilesRPX.html)
- Export: Section via export filters HTML, PDF, Text, RTF, Excel, TIFF; Page/RDLX via rendering extensions image, HTML, PDF, XML, Word, Excel (ASP.NET Core: XLSX, DOCX, PDF, CSV, JSON, TIFF) (exporting URL above)
- Paper sizes come from the printer driver; user-defined sizes need admin rights, one at a time (JP docs) (https://docs.mescius.jp/help/activereports-16/Printing(SectionReportTroubleshooting).html). Continuous-form/dot-matrix specifics: UNVERIFIED.

## Common patterns (facts)
- Banded model with absolute placement inside bands: Jasper, Crystal, ActiveReports Section, Stimulsoft, FastReport, Telerik, DevExpress, Pentaho (canvas mode). Flowing grid/tablix model: SSRS, BIRT, ActiveReports RDL/CPL, Telerik/SSRS tables. True fixed-page form model with declared overflow targets: ActiveReports Page reports only; Oracle form-like/mailing-label fix fields and truncate. List & Label: free page plus Report Container.
- Universal band set: report (title/summary), page header/footer, group header/footer, detail, column header/footer; extra: background/overlay/watermark (Jasper, Stimulsoft, FastReport, Pentaho, Crystal underlay), last-page footer (Jasper), no-data (Jasper), empty/filler (Stimulsoft), child/sub-band (Stimulsoft, FastReport, DevExpress), margin bands (DevExpress, Pentaho).
- Overflow controls recur under different names: can grow/shrink; keep together (band, group, header-with-first-detail); repeat header on new page; print at bottom / stack footer at bottom; start new page/column; print-when-detail-overflows; print on first/last/odd/even pages.
- Total page count requires a second pass or deferred evaluation: Crystal (full render), FastReport DoublePass, Stimulsoft DoublePass, Jasper evaluationTime=Report, SSRS computed at render, Telerik page sections only.
- Blank filler rows exist natively only in Stimulsoft (EmptyData), ActiveReports Page (RepeatBlankRows), List & Label ("fixed size" table).
- Pagination is renderer-dependent everywhere: SSRS soft vs hard page-break renderers, Telerik per-renderer paging, BIRT per-emitter header behaviour, SSRS multi-column PDF/TIFF only.
- Raw printer languages are rare: FastReport ZPL and VCL dot-matrix ESC/P, Stimulsoft text escape codes, Oracle PCL/PostScript/ASCII; others print through OS drivers or PDF.

## Terminology
- "Banded" (design surface made of recurring bands with free placement) vs "page based" (free page containing a table object) (https://kenhamady.com/reporting_tools_glossary.pdf)
- Section / Page / RDL reports; Fixed Page Layout (FPL) vs Continuous Page Layout (CPL) (https://developer.mescius.com/activereportsjs/docs/ReportAuthorGuide/report-configuration/Report-Layouts.md)
- Oracle report styles: tabular, group above, group left, form-like, form letter, mailing label, matrix (URL in §12)
- Crystal wizards: Standard, Cross-Tab, Mailing Label, OLAP (URL in §2)
- DevExpress: Table, Vertical, Cross-Tab, Labels; "standard tabular, master-detail, label reports, mail merges" (https://docs.devexpress.com/XtraReports/405621/desktop-reporting/winforms-reporting/end-user-report-designer-for-winforms/detailed-guides-win-eurd)
- SSRS: tablix, data region, table / matrix / list, "free-form report" (list), "invoices and forms" (URLs in §4)
- List & Label: list, label, card (file card) projects (URL in §8)
- Evisions Argos banded sub-types: List Report, Tabular, Form Style, Mailing Label (https://webhelp.evisions.com/HelpFiles/Argos/en/Content/Banded%20Reports%20-%20Report%20Types.html); Logi page-report components: banded, crosstab, table, chart (https://devnet.logianalytics.com/hc/en-us/articles/1500011463221-Lesson-3-Creating-and-Performing-Data-Analysis-on-Page-Reports)
- Cross-tab = cross-tabulation = matrix (BIRT) = PivotTable-like (SSRS) (https://eclipse-birt.github.io/birt-website/docs/overview-design/)
