# トポロジー {#topology}

トポロジーは文書が流れるネットワークです。あらゆる種類のノードと、その間のエッジです。サインインした全員が Topology ページで見られます。役割 topology を持つ人が Admin → Topology で組み立てます。

## ビュー {#view}

Topology ページは、管理者が置いた位置にノードを描き、その種類とエッジ、そして自分が見られるジョブ（自分のものと自分のグループのもの。管理者は全員のもの）の動きを示します。

- 各ノードの数。インボックスに留まった項目、ディスプレイで開いている伝票、プリンタやアーカイブで待つ配送、失敗した配送、直近 1 時間にそのノードへ到達したジョブです。
- エッジを走る点。直近 10 分のレグです。

背景をドラッグすると移動、ホイールかピンチで拡大縮小、Fit でトポロジー全体を収めます。ノードをクリックすると、そこにある自分のジョブが並び、送れるノードならそこに印刷できます（[Jobs](jobs.md#print) と同じフォーム）。ページはマネージャーをポーリングし、題名の横のバッジが動きの最終更新を示します。このページから何かを変えることはありません。

## エディタ {#editor}

Admin → Topology がエディタです。キャンバスと、選んだノードのサイドバーがあります。

- **+ Add a node** で種類のパレットが開きます。1 つ選ぶと新しいノードがキャンバスに現れ、サイドバーが開きます。名前と設定を入れて Add を押します。Escape で取りやめます。
- **ノードをクリック**するとサイドバーに開きます。設定と、そこにあるもの（[ノードのサイドバー](#sidebar)）です。Save でノードを書き込み、Delete か Delete キーで削除します。ほかのノードが送り先にしているノードは削除できません。先にエッジを外します。
- **ノードをドラッグ**すると動きます。ノードを描く位置は、ノード自体とは別に、全員のものとして保存されます（レイアウト）。
- **ノードの右側のポートから別のノードへドラッグ**するとつながります。エッジはノードの `to`（キュー、エンドポイント、CUPS サーバー、インボックス、テンプレートノード、変換ノード）、`members`（クラス）、`otherwise`（フィルタ。ルールのノードはルールの中で設定します）に加わるか、フォールバックプリンタになります（ディスプレイ）。エッジをクリックすると、確認のうえで外せます。
- Zoom、Fit、Refresh はビューと同じです。

ノードは Save のときに検査されます。名前で参照するノードが存在すること、名前がほかの種類のものでないこと、ノードへ戻る経路がないこと、到達するペイロードの種類をすべてのノードが受け取れること（[ペイロードの種類](flow.md#kinds)）です。ポートとエッジは流れるもので色分けされます。青は `.bdf` 文書、緑はデータ、灰色は受け取ったままのファイルです。受け取れない種類をノードに持ち込むエッジは拒否され、経路を示すメッセージが出ます。「laser (printer) takes bdf, but any reaches it: raw → fan → laser」のようにです。設定の下の 1 行が、入口から推定した、そのノードが受け取るものと送り出すものを示します。

### 名前と題名 {#names}

ノードの名前は英数字と `.`、`_`、`-`（64 文字まで）で、後から変えられません。ノードの IPP の宛先 `/ipp/print/<name>` であり、アプリケーションやほかのノードが参照するものだからです。題名は、場所があれば名前の代わりに表示されます。ディスプレイ、プリンタ、シンクは種類を変えられません。それ以外の種類のノードは、名前を保ったまま、それ以外の種類の間で変えられます。

### ノードのサイドバー {#sidebar}

種類ごとの設定（[ノードの種類](nodes.md)）のほかに、保存済みのノードのサイドバーには次のものがあります。

- IPP の URL と、そこへ送られたジョブ（Admin → Jobs）、そのインボックス（Admin → Inboxes）、そこで待つ配送（Admin → Deliveries）へのリンク。
- エンドポイントなら、入口（アプリケーションが POST する URL）とキー。Rotate key で新しいキーを作り、1 度だけ表示します（[エンドポイント](entries.md#endpoints)）。
- テンプレートノードなら、テンプレート。アップロード、それぞれが引く項目、ファイル、削除です（[テンプレートとデータ](templates.md)）。
- ディスプレイなら、デバイスと最後に見た日時、そして Add a device。1 度きりのコードと QR コードを表示します（[ディスプレイボード](displays.md)）。
- CUPS サーバーノードなら、コンピュータがプリンタを追加する URL と、一覧するコマンド（[CUPS サーバーノード](entries.md#cups)）。
- シンクなら、保持している最新の文書とそのページ。
- プレビューのあるプリンタなら、偽プリンタが受け取ったもの（[プリンタ](nodes.md#printer)）。
