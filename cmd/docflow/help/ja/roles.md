# サインイン・役割・監査 {#sign-in-roles-and-audit}

## サインイン {#sign-in}

デバイスの `/tablet` 以外のすべてのページは、組織の ID プロバイダ（OpenID Connect）でサインインした人のためのものです。プロバイダがサインインさせた人は、運用者のルール（発行者、メールのドメイン、グループ）が許せば、ここでの登録なしに入れます。プロバイダが伝える所属グループはサインインのたびにコピーされ、誰が管理者かはリクエストごとに判定されます。「サインアウト」はここでのセッションを終え、次のサインインではプロバイダがどのアカウントを使うか尋ねます。

## 役割 {#roles}

| 役割 | ページ | |
|---|---|---|
| サインインした全員 | ジョブ、トポロジー、ヘルプ | 送れるノードに印刷する。自分のジョブと自分のグループのジョブを見る |
| `topology` | エディタとしてのトポロジー。管理 → アプリ、インボックス、ジョブ、配送 | ネットワークとそこにあるもの（ノード、テンプレート、キー、アプリ、デバイス、インボックス、配送）を組み立てる。すべてのジョブを見る |
| `audit` | 監査 | 監査ログと、すべてのジョブ（閲覧） |
| 管理者 | すべて | 両方の役割と、管理トークンとしての API |

誰がどの役割を持つかは運用者の設定です。本人の ID か確認済みのメールアドレスで、またはグループのメンバーとして指定します（[サインイン](operate.md#oidc)）。持っていない役割のページを開くと、そう表示されます。

## ノードのスコープ {#scopes}

すべてのノードにスコープと所有者があり、トポロジーのサイドバーで設定します。

| スコープ | ページから送れる人 | ジョブが誰のものか |
|---|---|---|
| `shared`（既定） | サインインした全員 | 送り手だけのもの |
| `group`、所有者にグループ | グループのメンバー | グループのもの。メンバーが見られます |
| `personal`、所有者に本人のメールアドレス | 本人 | 本人のもの |

自分のグループを持たないディスプレイは、フォールバックプリンタのグループをジョブに与えます。ノードがグループを与えないとき、アプリのジョブはアプリのグループのものです。スコープはアプリケーションや IPP クライアントには関わりません。エンドポイントはキーかアプリが送るものを受け取り、IPP はサブミットトークンが許すものを受け取ります（[文書の入口](entries.md)）。

## ジョブを見られる人 {#who-sees}

ジョブには、マネージャーが確認した送り手（サインインした人、アプリ、トークン、エンドポイント、匿名）が、送り手が名乗った名前（「（… として）」と表示）とは別に記録されます。送り手はジョブを見られ、そのグループのメンバーも見られ、管理者と監査者はすべてのジョブを見ます。取り消せるのは送り手と管理者で、アプリはスコープ `jobs.cancel` があれば自分のジョブを取り消せます。再印刷は、再印刷した人の新しいジョブです。

## 監査 {#audit}

監査のページ（役割 `audit`）には、誰が何をしたかが新しい順に並びます。日時、誰が、操作、対象、詳細です。`GET /api/audit` は同じログです。記録されるもの:

| 操作 | |
|---|---|
| `login`、`login-refused` | サインインと、ルールが拒否したサインイン |
| `put-node`、`delete-node` | ノードの保存と削除 |
| `rotate-key` | エンドポイントのキーの更新 |
| `put-template`、`delete-template` | テンプレートのアップロードと削除 |
| `put-app`、`delete-app`、`rotate-app-secret` | アプリの登録・変更、削除、シークレットの更新 |
| `enrollment-code`、`enroll`、`remove-device` | ディスプレイのコードの発行、デバイスの登録、デバイスの削除 |
| `refuse-document` | 入口が形式を理由に文書を拒否した |
| `token-refused` | `/oauth/token` でアプリの資格情報が拒否された |
| `oauth-code`、`user-token`、`code-refused` | 公開クライアントに人のためのコードを発行した、そのコードから人のトークンを作った、コードの交換を拒否した |
| `export-document` | エクスポートから文書がダウンロードされた。誰がしたか |
| `release-item`、`discard-item` | インボックスの項目の送り出しと破棄、および誰がしたか |
| `cancel-job`、`reprint` | ジョブの取り消し、ジョブの再印刷 |

ログの下には、最近のジョブとそれぞれがたどった経路が並びます。
