Forms

Pick a template: a workbook, a document or a deck with tags such as {{customer}} where the values go, a PDF with form fields, or a template made with the designer of pdfme. Its tags or fields are read, a form is made of the JSON Schema of the data they ask for, and what you type fills the template: the filled form is drawn here, and saved as a PDF file (tagged, or PDF/A, when you choose so). It is done by the Go packages a server does it with (form, vector/pdfbdf), built as WebAssembly. The template and the data are not uploaded anywhere.

(.xlsx, .docx, .pptx, .pdf, a .json of pdfme, .bdft) or drop one anywhere on the page.
