# Curated mappings for gen-drawio-awsmap: what the automatic matching of
# names gets wrong or misses. Each line names a shape of an older AWS
# generation and its target in the current AWS palette (Sidebar-AWS4.js):
#
#   res:<resIcon>          a service icon (shape=mxgraph.aws4.resourceIcon)
#   <stencil>              a resource icon (shape=mxgraph.aws4.<stencil>)
#   group:<grIcon>         a group (shape=mxgraph.aws4.group or groupCenter)
#   rect:<title>           a group drawn as a rectangle (Availability Zone,
#                          Security group), title lowercased with _
#   groupicon:<grIcon>     the icon of a group alone, colored as in the group
#   builtin:<style>        a draw.io shape that keeps the cell's colors
#   -                      no current counterpart: drawn as a rectangle
#
# A palette entry that appears in several categories is picked with
# @<Category> (spaces as _); otherwise the first in palette order is used.
# Run go run ./tools/gen-drawio-awsmap -v to see every decision.
