## A. Japanese 帳票 products

### WingArc1st SVF (SVF Designer / X-Designer, SVF for PDF / Java Print / Web, SVF Cloud)
- Design model: a **フォーム** (XML様式ファイル) contains **サブフォーム** (repeat area) containing **レコード** = "サブフォーム内で繰り返しデータが出力される行"; 合計レコード (小計/中計/大計), 総計レコード and ヘッダーレコード are special record types placed in/around the subform (https://repo.svfcloud.com/manual/release/ja/xdesigner/ja/1237840.html ; https://repo.svfcloud.com/manual/release/ja/xdesigner/ja/record-properties-basic-settings-tab.html).
- 明細 fixed vs variable: the record count per page is whatever fits the subform frame ("表示行数" preview). Overflow: "サブフォームにレコードを印字して領域を超えた場合は、通常は改ページをして、以降新たなページに印刷されます"; optional **リンクサブフォーム名** continues records into another subform in the same form (e.g. 1ページ目 鑑+明細, 2ページ目以降 明細のみ — KB title "1ページ目に鑑+明細、2ページ目以降は明細のみを出力するには" https://cs.wingarc.com/ja/kb/000021816, body not fetched). "レコード数に関わらず、枠の大きさは固定にする" draws ruled lines to the full frame when data ends early (fixed-row look); "データがないとき、サブフォームを印刷しない" (https://repo.svfcloud.com/manual/release/ja/xdesigner/ja/subform-properties-basic-tab.html).
- Totals on last page only: field property **最終ページのみ** ("同一キーの印刷が複数ページにまたがったとき…最後のページのみ"), **先頭ページのみ**, 合計/ヘッダーレコード printed at キーブレイク, **改ページ** at key break, **グループサプレス**, **累計値のクリア**, **ページカウントのクリア** (https://repo.svfcloud.com/manual/release/ja/xdesigner/ja/1237828.html). Total records can be forced "サブフォーム内に入らない場合も、印刷する" and "固定位置に出力"; 印刷モード chooses "大計、中計、小計、明細" (totals first) vs "明細、小計、中計、大計" (record-properties page above).
- 繰越: no field named 繰越; built from R-series running functions (RSUM/RCOUNT… "累計", reset by 累計値のクリア), P-series = ページ合計 (PSUM, edit-formula only), G-series = all data (https://repo.svfcloud.com/manual/release/ja/xdesigner/ja/statistical-functions2.html) plus system variables `_PREV_P` (1 = carried over from previous page), `_NEXT_P` (1 = continues to next page) for 「前頁より/次頁へ」 labels.
- ページ総数 "1/3": `_PAGE_CNT` (page no. within key-break unit), `_TOTAL_PAGE_COUNT`, `_TOTAL_PAGE_CNT` (per key break), `_SERIAL_PAGE_COUNT`; the TOTAL ones need report-writer mode (VrSetForm mode 4/5) and run the job twice ("プログラムを2回実行するため…遅くなります") (https://repo.svfcloud.com/manual/release/ja/xdesigner/ja/system-variables-design-functions.html).
- 連帳: 用紙サイズ offers はがき/A5/A4/A3/B5/B4/レター/**連帳**/フリー; 連帳 height in 1/6 inch, width in inch (default 11×15 in); "連帳の縦サイズを3の倍数となるように指定することで改ページずれを防げます" on dot printers; **綴り枚数** 1–30 (not for dot printers) and **複写部数** (https://repo.svfcloud.com/manual/release/ja/xdesigner/ja/paper-properties.html). Dot printers (ESC/P, PC-PR201) default to 24-dot text and suppress 固定文字/罫線/ビットマップ unless enabled (FAQ https://repo.svfcloud.com/manual/release/ja/xdesigner/ja/1238099.html). Marketing: "複写伝票の出力をドットプリンターからレーザープリンターに簡単に移行", 綴り伝票, コマンド印刷 without Windows driver (https://www.wingarc.com/welcome/svf/wh/index.html).
- フォームオーバーレイ: not an SVF term in the manuals reached; nearest: SVF Ver.9 "PDFレイヤー機能" (designer layers kept in PDF) (https://cloud.watch.impress.co.jp/docs/news/688973.html). UNVERIFIED: PDF background overlay feature.
- Template import/Excel: SVF Ver.10 can use Excel files directly as the form format (https://cloud.watch.impress.co.jp/docs/news/1221896.html); SVF Cloud X-Designer: drag-and-drop, barcodes, charts, conditional formatting, PDF/Excel/Word output, direct printing, 26 languages (https://www.sap.com/sea/products/technology-platform/partners/wingarc1st-inc-svf-cloud.html).
- 和暦: functions SEI2WA1/SEI2WA1Z/WA2SEI/NENGO/WYEAR; second arg "1" gives "R01年…" (https://cs.wingarc.com/ja/kb/000000382); new era via ini "Nengou5=…" (https://cs.wingarc.com/ja/kb/000001459). 外字: EUDC.TTE registered in SVF Cloud Manager / "EUDC" soft font on-prem (https://repo.svfcloud.com/manual/release/ja/manager/scmguid/ja/892158.html). 縦書き: property 文字の方向 (縦/横) with right-top origin (https://repo.svfcloud.com/manual/release/ja/xdesigner/ja/1237827.html). Barcodes NW7/CODE39/JAN/ITF/CODE128/郵便カスタマ/EAN128; QR/Maxi/PDF417/DataMatrix (https://repo.svfcloud.com/manual/release/ja/xdesigner/ja/1237880.html).

- **Oracle BI Publisher**: RTF form fields `<?for-each:G?>…<?end for-each?>`, `<?if:…?>`, `<?split-by-page-break:?>` before end for-each (PDF/RTF/PPT only), `<?start@last-page:body?>…<?end body?>` for last-page-only content, `<?attribute@block:xdofo:rowspancell-repeat-nextpage;'true'?>` (https://docs.oracle.com/en/middleware/bi/analytics-server/design-publish/template-features.html). Excel templates: defined names `XDO_?FIELD?`, `XDO_GROUP_?G?`, `XDO_METADATA` sheet; native formulas break with nested groups (https://docs.oracle.com/middleware/12212/bip/BIPRD/GUID-0A62F78E-3B19-4BA6-8C9F-2757D2104782.htm).

- **Docmosis**: `<<field>>`, `<<rs_x>>…<<es_>>` sections, `<<rr_x>>`/`<<er_>>` table rows, `:stepN`, `<<cs_{expr}>>` conditions, `<<img_x>>`/`imgfit_`, `$idx`; tag-only lines removed; Word/LibreOffice templates → PDF/DOCX (https://resources.docmosis.com/Documentation/Docmosis-Java/4.7.5/Docmosis-Template-Guide.pdf).

## Common patterns
- Two template families: **absolute-positioned forms** (SVF, Create!Form, ActiveReports page report, pdfme, プリントクリエイター: fixed frame, rows that fit, blank-row fill) vs **flow/banded** (ActiveReports section, OPRO bands, Smart Forms main window, HTML/XSL-FO/Typst).
- Repeat scoping is inferred from the container: table row (docxtemplater, Carbone, Aspose, Conga, Docmosis rr_, BI Publisher), paragraph/section (rs_, foreach), slide/sheet (Templater, Carbone ODP), with a marker pair (start/end tags) or a single row with `[i]/[i+1]` sentinels (Carbone) or no marker at all (Templater, VB-Report `**` cells).
- "Page N of M" always costs a second pass (SVF `_TOTAL_PAGE_COUNT`, ActiveReports PageCount delaying header rendering, XSL-FO citation-last, Typst `final()`).
- Carry-forward is rare as a primitive: BI Publisher brought/carried-forward and SVF `_PREV_P/_NEXT_P` + RSUM; others compute it in data.
- Office-template engines leave pagination to Word/LibreOffice; Japanese tools control it explicitly (行数で改ページ, キーブレイク改ページ, 連帳 1/6-inch pitch).
- Spreadsheet formulas are fragile under row insertion (Carbone post-injection recalc, Templater adjusts, VB-Report cannot cross Repeat boundary, BI Publisher nested groups).

## Terminology (Japanese → English)
- 帳票 — business form/report; 固定帳票 — fixed-layout (pre-positioned) form; 可変帳票 — variable/flowing report.
- 明細 — detail/line items (ActiveReports Detail section, OPRO Band, SVF レコード); 鑑 — cover/header page of a multi-page document.
- 繰越 (前頁より繰越 / 次頁へ繰越) — brought forward / carried forward totals; 小計/中計/大計/総計 — subtotal levels / grand total; 累計 — running total; ページ合計 — page total.
- キーブレイク — control/group break; 改ページ — page break; ページあふれ — overflow; 空行埋め — blank-row fill (RepeatToFill).
